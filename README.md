### 🌟 Projeto em Destaque: Motor SGBD em Java Puro

> *Construindo um Sistema Gerenciador de Banco de Dados relacional do zero para dominar a ciência dos dados em baixo nível.*

```
      [ SQL / Query Engine ]
                ↓
    [ Buffer Pool Manager (RAM) ]
                ↓
   [ B-Tree Indexing / Slotted Pages ]
                ↓
      [ Storage Engine (Disk I/O) ]
```

- **O Desafio:** Criar um motor de banco de dados sem bibliotecas prontas, manipulando arquivos binários de dados, páginas de tamanho fixo e árvores de busca.
- **Refatoração Ativa para POO:** O projeto nasceu inicialmente com lógica procedural e agora passa por uma **reestruturação arquitetural completa para Orientação a Objetos**, isolando responsabilidades em classes e componentes modulares.
- **Conceitos Aplicados:**
  - `Storage Engine`: Paginação de disco e alocação de registros.
  - `Buffer Pool`: Cache em memória para minimizar acessos de I/O.
  - `B+ Tree`: Algoritmos de indexação balanceada em disco.
  - `Transações`: Confiabilidade e propriedades ACID.
